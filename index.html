Descripción del Proyecto

Este proyecto consiste en la creación y edición de un video utilizando el programa Kdenlive. El objetivo es mostrar diferentes técnicas básicas de edición, transiciones y efectos para crear un resultado visual entretenido.

El video es una recopilación de momentos aleatorios y graciosos ocurridos en España a lo largo del tiempo, con un tono humorístico y dinámico.

Aspectos Técnicos

Software utilizado

Kdenlive, editor de video gratuito y de código abierto.

Transiciones y efectos

  • Fundidos a negro
  • Desvanecidos
  • Textos entre clips
  • Efectos de sonido

Banda sonora

Música flamenca, efectos cómicos y sonidos de suspense para reforzar el tono humorístico del video.
